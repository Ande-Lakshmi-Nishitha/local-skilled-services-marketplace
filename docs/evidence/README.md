# Evidence

These files were generated by the project's own scripts while it was being built and tested
(Linux, Node 22, PostgreSQL 16 with pgvector 0.6, MongoDB 8, model all-MiniLM-L6-v2 fp32).
Re-run them on your machine before the submission so the numbers in your report are your own:

| File | Regenerate with |
|---|---|
| `sql-tests.md` | `npm run test:db` |
| `concurrency-tests.md` | `npm run test:concurrency` (and `-- --http http://localhost:3000` with the app running) |
| `eval-results.md` | `npm run eval -- --grid` |
| `bench-results.md` | `npm run bench` (timings depend on your hardware) |
