# Index benchmarks

Generated by `npm run bench` on 2026-11-11. Times are medians of 40 EXPLAIN ANALYZE runs with random parameters.

## 1. Availability lookup: "next 5 open slots of a worker" (300,000 slots, 3,000 workers)

```sql
SELECT slot_id, start_time FROM bench.slot WHERE worker_id = $1 AND status = 'open' AND start_time > now() ORDER BY start_time LIMIT 5
```

| index | median time | plan |
|---|---|---|
| none | 13.95 ms | Limit > Sort > Gather > Seq Scan |
| plain (worker_id) | 0.19 ms | Limit > Sort > Bitmap Heap Scan > Bitmap Index Scan (bench_slot_worker) |
| partial (worker_id, start_time) WHERE status = 'open' - the one in migration 001 (5560 kB) | 0.04 ms | Limit > Index Scan (bench_slot_partial) |

## 2. Vector search: top-10 by cosine distance (20,000 vectors x 384 dims)
